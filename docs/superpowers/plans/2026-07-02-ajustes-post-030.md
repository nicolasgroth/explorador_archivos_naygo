# Ajustes post-0.3.0 — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ocho ajustes de UX post-0.3.0: submenú "Abrir ▸" (otro panel/nuevo/Explorador), sistema de metadata por tipo en Propiedades y Preview, botón calcular tamaño de carpeta, split por el lado más largo, Ctrl+Enter en nueva carpeta, instalador bilingüe, y atajos de abrir en panel.

**Architecture:** La mayoría cablea funciones ya probadas (`resolve_target`, `compute_size_active`, `open_default`, `add_pane_split_dir`). El único subsistema nuevo es `core::metadata` (trait `MetadataProvider` + registro por extensión) con un proveedor de imágenes en core y uno de versión-de-exe en platform, leído por un worker async en la UI. Todo lo pesado corre bajo demanda, en worker, cancelable.

**Tech Stack:** Rust, Slint 1.16, crate `image` (ya presente, dimensiones), crate `windows` (Win32 `GetFileVersionInfo` — requiere feature `Win32_System_Version`), Inno Setup (`.iss`).

**Rama:** `feat/ajustes-post-030` (creada; spec en `ec09b68`).

**Build:** `cargo build`/`cargo test` desde la raíz. UI Slint con `CARGO_BUILD_JOBS=2` si el compilador crashea. Cada commit termina con la firma de coautoría del repo. Header Naygo en archivos nuevos. i18n: los `*.json` en `crates/core/src/i18n/` son PLANOS (`"slint.x.y": "valor"`); cablear en `i18n_keys.rs` (`tr.set_x_y(c.t("slint.x.y").into())`) y declarar la property en `i18n.slint` (global `Tr`). Toda clave nueva va en los 10 idiomas.

- [ ] **Step 3: Implementar el helper**

```rust
/// Elige la orientación del split para aprovechar el lado más largo del panel: si es más ancho
/// que alto, divide en columnas (`Horizontal` = hijos lado a lado); si es más alto que ancho,
/// en filas (`Vertical`); en empate, `Horizontal` (el default histórico). Puro y testeable.
pub fn pick_split_dir(rect: Rect) -> SplitDir {
    if rect.h > rect.w {
        SplitDir::Vertical
    } else {
        SplitDir::Horizontal
    }
}
```

```rust
    pub fn ctx_open_other_pane(&mut self, area: naygo_core::workspace::layout::Rect) {
```

```rust
//! Metadata extra por tipo de archivo, extensible: cada `MetadataProvider` sabe leer los
//! campos de un tipo (imagen, exe, …). El registro mapea extensión → proveedor. Puro salvo
//! los proveedores que toquen el SO (esos se inyectan desde `platform`). Tolerante: un
//! proveedor que falla devuelve vacío; nunca panic (el filesystem es hostil).

use std::path::Path;

pub mod image_meta;

/// Un campo de metadata: la clave i18n de su etiqueta + el valor ya formateado.
#[derive(Clone, Debug, PartialEq)]
pub struct MetadataField {
    pub label_key: &'static str,
    pub value: String,
}

/// Un proveedor de metadata para uno o más tipos de archivo.
pub trait MetadataProvider: Send + Sync {
    /// Extensiones (lowercase, sin punto) que este proveedor maneja.
    fn extensions(&self) -> &'static [&'static str];
    /// Lee los campos del archivo. Vacío si no aplica o falla.
    fn read(&self, path: &Path) -> Vec<MetadataField>;
}

/// Proveedores registrados. Los de `core` se listan aquí; los de `platform` (p. ej. versión de
/// exe en Windows) se AGREGAN en runtime vía `register_provider` al arrancar la app.
use std::sync::RwLock;
static REGISTRY: RwLock<Vec<Box<dyn MetadataProvider>>> = RwLock::new(Vec::new());

/// Registra un proveedor (idempotencia no garantizada; llamar una vez por proveedor al iniciar).
pub fn register_provider(p: Box<dyn MetadataProvider>) {
    if let Ok(mut reg) = REGISTRY.write() {
        reg.push(p);
    }
}

/// Asegura que los proveedores de `core` estén registrados (imagen). Idempotente vía Once.
fn ensure_core_providers() {
    use std::sync::Once;
    static ONCE: Once = Once::new();
    ONCE.call_once(|| {
        register_provider(Box::new(image_meta::ImageMeta));
    });
}

/// Devuelve los campos de metadata del archivo `path` buscando un proveedor por su extensión.
/// Vacío si no hay proveedor o si falla. Es la entrada única que consume la UI.
pub fn metadata_for(path: &Path) -> Vec<MetadataField> {
    ensure_core_providers();
    let ext = match path.extension().and_then(|e| e.to_str()) {
        Some(e) => e.to_ascii_lowercase(),
        None => return Vec::new(),
    };
    let reg = match REGISTRY.read() {
        Ok(r) => r,
        Err(_) => return Vec::new(),
    };
    for p in reg.iter() {
        if p.extensions().iter().any(|e| *e == ext) {
            let fields = p.read(path);
            if !fields.is_empty() {
                return fields;
            }
        }
    }
    Vec::new()
}

mod tests {
    use super::*;
    // (tests del Step 1)
}
```
